# Llama-70B 프로파일 DB 문제 분석 및 수정

## 1. 문제 요약

### 배경
- Optimus-Prime-FASOp에서는 (mbs, 9) 또는 (mbs, 10) 형태의 프로파일 DB를 사용하여 학습 시간을 예측함
- 프로파일 DB는 JSON 파일에서 추출한 연산별 시간 데이터를 numpy 배열로 저장

### 발견된 문제
1. **행 순서 오류**: JSON 파일을 파일명 기준 문자열 정렬하여 mbs 순서가 잘못됨
2. **열 개수 차이**: mbs-9 버전은 lm_head 열이 누락됨

### 원인
- `sorted(glob.glob(...))`로 JSON 파일을 읽을 때 **문자열 정렬** 적용
- 예: "128-16" < "16-2" < "32-4" < "64-8" < "8-1" (문자열 비교)
- 결과적으로 mbs=1 (파일명 "8-1")이 항상 맨 뒤로 정렬됨
